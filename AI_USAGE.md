# AI usage disclosure

## Tools used

OpenAI Copilot SDK in VS Code was used to help implement and review this project.

## Representative prompts

- “Build a responsive, functional task dashboard from the FocusBoard assignment brief.”
- “Implement task creation, editing, deletion, status updates, search, priority filters, derived statistics, and localStorage persistence.”
- “Make the task dashboard usable at mobile, tablet, and desktop widths with accessible controls.”

## AI-assisted areas

The app structure, React components and state logic, dashboard styling, sample tasks, and project documentation were AI-assisted. The implementation was checked with the TypeScript/Vite production build, linting, and browser interaction checks.

## Suggestion reviewed

Automatic Focus Notes rotation was not added. The brief says autoplay is unnecessary; explicit previous/next buttons and slide indicators keep navigation predictable and avoid moving content unexpectedly.
